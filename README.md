# 🎯 Number Guessing Game

## 📌 Project Description
The Number Guessing Game is a web-based application developed using Python Flask, HTML, and CSS. The application generates a random number between 1 and 100, and the user must guess the correct number.

The application provides hints such as "Too High" and "Too Low" to help users find the correct number. It also tracks the number of attempts and displays the complete guess history.

## 🚀 Features

- Generates a random number between 1 and 100.
- Allows users to enter their guesses.
- Displays hints such as Too High and Too Low.
- Tracks the total number of attempts.
- Displays guessed numbers with their results.
- Maintains a guess history table.
- Displays a congratulatory message when the correct number is guessed.
- Provides a Play Again option for multiple rounds.
- Handles invalid user inputs.
- Responsive and attractive web interface.

## 🎮 How to Play

1. Open the application in your browser.
2. Enter a number between 1 and 100.
3. Click the Submit Guess button.
4. Follow the hints displayed on the screen.
5. Check your previous guesses in the Guess History table.
6. Continue guessing until you find the correct number.
7. Click Play Again to start a new round.

## 📊 Application Features

| Feature | Description |
|---------|-------------|
| Random Number | Generates a number between 1 and 100 |
| Guess Input | Accepts numbers from the user |
| Hints | Displays Too High or Too Low |
| Attempts Counter | Tracks the number of guesses |
| Guess History | Displays all previous guesses and results |
| Play Again | Starts a new game |
